# TEST

Тестовый Python-проект для проверки работы Git и GitHub.

## Описание

Проект создан для проверки:
- Подключения локального проекта к GitHub.
- Настройки имени и электронной почты автора коммитов.
- Отправки изменений в удалённый репозиторий.
- Отображения профиля автора на GitHub.

## Запуск

Установите Python и выполните команду:

```bash
python main.py
```

## Структура проекта

- `main.py` — основной файл программы.
- `README.md` — описание проекта.
- `.gitignore` — список файлов, которые Git не должен отслеживать.
